# solar_power_calculator
A Python program that calculates solar panel power output based on irradiance, panel area, and efficiency. The program also classifies the generated power as low, moderate, or high.

## Features
- Calculates solar power output
- Classifies power levels
- Demonstrates Python functions and conditional statements

## Formula
Power = Irradiance × Panel Area × Efficiency

## Sample Output

Morning power: 160.0 W moderate
Afternoon power: 360.0 W high
Evening power: 80.0 W low
